# Thrijwal Krishnappa – Portfolio

Personal portfolio built with Next.js, React and Tailwind CSS, deployed on Vercel.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Edit content
- Projects: `components/projects-section.tsx`
- Experience: `components/experience-section.tsx`
- Skills: `components/skills-section.tsx`
- Certifications: `components/certifications-section.tsx`
- Contact links: `components/contact-section.tsx`
